# 拾光 · Personal Desk

一个本地运行的个人工作台。把工作、学习、生活、购物放进同一张日程里，用清爽的时间面板安排今天和这一周；食品、优惠券和会员到期日也可以单独记下来。

页面使用原生 HTML / CSS / JavaScript 编写，没有构建步骤，也没有外部依赖，数据保存在浏览器本地。

## 功能

- **今日总览**：问候、今日待办、已完成事项、进行中事项、迷你月历、即将到期、期限提醒、本周节奏；今日日程可按分类筛选
- **来源标签**：分类可以维护标签预设，事项支持多选标签；工作可按项目、会议、汇报区分，学习可按阅读、课程、复习区分，购物可按日常开销、大额支出区分
- **循环任务**：支持每天、每个工作日、每隔 N 天、每周、每月重复；可以设置重复结束日期
- **自动顺延**：没有 DDL 的未完成独立事项，过了安排日期会自动顺延到今天，并保留原安排日期
- **跨天进行中**：有 DDL 的未完成事项，从安排日期之后到 DDL 当天会继续出现在今日日程的「进行中」区，并显示起始日期和截止时间
- **期限记录**：单独记录食品、日用/护肤、药品、优惠券、会员/订阅等会过期的东西；支持直接填到期日，或按生产日期和保质期自动计算；按到期日显示已过期、今天、7 天内和 30 天内状态
- **分类视图**：循环任务折叠为系列卡片，独立事项和循环任务分开统计，并可按来源标签筛选
- **自定义分类**：侧栏新建分类，支持名称、图标、颜色和标签预设，并可随时编辑或删除
- **事项管理**：新建、编辑、完成、恢复、删除；支持安排日期、开始/结束时间、DDL、优先级、备注和来源标签
- **本周时间线**：按天查看安排和 DDL，支持上一周/下一周、分类筛选
- **全局搜索**：搜索事项标题、备注、分类名称、来源标签，以及期限记录的名称、类型和备注；循环任务按系列去重
- **本地助手**：用自然语言式短指令新建、完成、查询和跳转页面，详见下方说明
- **到期提醒**：今日截止、即将到期、已逾期和剩余天数提示
- **本地持久化**：每次修改自动写入浏览器 `localStorage`
- **响应式布局**：窄屏下收起侧栏，使用移动端导航和单列卡片
- **快捷键**：`N` 新建事项，`/` 聚焦搜索，`Esc` 关闭弹窗、搜索或移动侧栏

## 来源标签

- 每个分类可以维护一组标签预设，例如 `工作` 分类默认包含「项目、会议、汇报」。
- 新建或编辑事项时，可以多选标签，也可以在输入框里直接创建新标签。新标签会自动收进当前分类的预设。
- 分类页的「来源」一行会列出该分类当前用到的标签，点击即可筛选独立事项和循环系列。
- 搜索结果会展示标签和循环徽标，输入标签名也能命中。

## 今日日程分类筛选

- 总览的今日日程上方有「全部 / 分类名」筛选胶囊，只显示所选分类当天的安排。
- 分类胶囊上的数字是当天该分类的全部事项数，包含已完成事项和「进行中」事项；页面顶部的待办数会随筛选更新。
- 切换日期时筛选会保留。如果所选分类当天没有安排，会显示空状态和「查看全部分类」入口。
- 在筛选状态下通过日程区添加事项，会默认选中当前筛选的分类。
- 「进行中」只在今天的总览里补充显示；切换到其他日期时，仍按那一天的安排显示。

## 循环任务

- 重复频率：每天、每个工作日、每隔 N 天、每周（以开始日期的星期为锚点）、每月（以开始日期的日号为锚点）。
- 「每隔 N 天」以系列开始日期为锚点，按固定天数间隔出现。例如从 10 月 29 日开始每 2 天，会在 10/29、10/31、11/02……出现。
- 「开始/结束时间」只是当天的时段，不会跨天。循环任务只在实际重复日出现；例如系列开始日期是周一，就只在周一生成，不会因为「重复结束」覆盖一整周而每天出现。
- 「重复结束」可选；不填时会一直循环。它只停止后续生成，不是每天的显示截止日期。
- 想让一件事连续多天留在今日日程，应使用「安排日期 + DDL」，它会进入「进行中」区，而不是把当天时间设成一整周。
- 系统会在本地生成今天前 31 天到未来 180 天之间的具体事项，所以跨天打开、搜索和日历视图都能正常看到。
- 已完成的具体事项会保留；编辑循环系列时，修改会同步到之后未完成的事项，已完成记录不会被改写。
- 同一循环系列在「进行中」里只补充最近一次未完成的具体事项；如果当天已有该系列的重复事项，就不会再重复显示。
- 在循环事项的编辑弹窗中删除时，可以选择：
  - **仅跳过本次**：系列继续，但这一天不再生成。
  - **删除整个系列**：移除系列和它的全部具体事项。
- 停止循环会将当前这一次保留为独立事项，并移除未来未完成的具体事项。
- 分类页、侧栏待办数、搜索结果和即将到期列表都会按系列去重，避免同一条循环出现很多次。

## 安排日期与自动顺延

- 事项里的「安排日期」表示计划在哪一天处理，DDL 则单独表示最晚截止要求。
- 没有 DDL 的独立事项如果没有完成，过了安排日期会自动顺延到今天；卡片上会显示「顺延自 X月X日」，编辑弹窗也会保留原安排日期。
- 顺延不会影响已完成事项：已经完成的记录留在原来的日期，方便回看。
- 有 DDL 的未完成事项不会改写原安排日期；从安排日期之后到 DDL 当天，会以「进行中」继续显示在今日日程里，并保留到期提醒。
- 「进行中」卡片的时间栏显示「进行中 / 至 X/X」，标签显示起始日期；同一循环系列只补充最近一次未完成事项，避免重复。
- 循环任务按系列日期生成，不参与独立事项的自动顺延；如果某次具体事项带有 DDL，也会在重复日之后进入「进行中」。
- 如果不想让跨天事项继续出现在今日日程，可以完成、删除它，或把 DDL 改到当天。

## 期限记录

- 侧栏的「期限记录」独立于待办事项，用来记录食品、日用/护肤、药品、优惠券、会员/订阅和其他会过期的东西。
- 每条记录包含名称、类型、到期日和可选备注；到期日可以是未来日期，也可以直接记录已经过期的日期。
- 到期日有两种填法：直接选择到期日，或填写生产日期和保质期（天 / 个月 / 年）自动计算。按月或按年计算时，月末会自动取目标月份的最后一天。
- 自动计算的记录会在卡片上显示生产日期和保质期来源；编辑时可以随时切回直接填写到期日。
- 状态会按当天日期实时计算：已过期、今天到期、7 天内、30 天内和更晚；页面顶部显示全部、7 天内和已过期的数量。
- 页面支持「全部 / 7 天内 / 30 天内 / 已过期」筛选，并按到期日从近到远排列。已过期记录会保留，方便回看，不需要时再删除。
- 总览右侧会增加「期限提醒」卡片，列出 30 天内或近 30 天已过期的记录；侧栏导航会显示已过期和 7 天内到期的数量。
- 全局搜索可以按名称、类型、备注、生产/保质期或日期找到期限记录，点击结果会直接打开编辑弹窗。
- 期限记录只保存在本机，不会发送浏览器通知或系统通知；它是一份本地视觉提醒，不会自动变成待办事项。

## 本地助手

右下角的「助手」按钮会打开一个本地对话框。它直接操作当前页面的同一份 localStorage 数据，不发起网络请求。

可以直接输入：

```text
今天还有什么
明天 10:00 写周报 @工作 #汇报
每天 8:00 晨跑 @生活 #健康
每两天 拉伸一下 @生活 #健康
每周三 19:00 阅读时间 @学习 #阅读
每月5日 交房租 @生活 #日常开销
完成晨跑
把晨跑标记完成
打开本周
打开期限记录
打开工作
搜索 发票
```

支持的规则：

- `@分类名` 指定分类，`#标签名` 添加来源标签。
- `今天 / 明天 / 后天 / 周X / 下周X / X月X日` 指定日期。
- `上午/下午/晚上 X点` 或 `HH:MM` 指定开始时间。
- `每天 / 工作日 / 每两天 / 每隔N天 / 每周X / 每月X日` 创建循环系列。
- `完成 / 勾掉 / 把……标记完成` 完成最匹配的待办；如果有多件相近事项，会先列出让你写得更具体。
- `打开总览 / 打开本周 / 打开期限记录 / 打开分类 / 新建事项` 跳转页面。
- `搜索关键词` 打开全局搜索。

**重要限制**：这是一个本地规则指令助手，不是联网的大模型聊天窗口。它不会理解任意自然语言，也不会上传数据。真正接入 AI 需要额外的模型 API、本地模型服务或 OpenCode 桥接，目前没有包含在静态页面里。

## 运行方式

### 方式一：直接打开（最简单）

双击 `index.html` 即可。样式和脚本全部使用相对路径，不需要联网。

### 方式二：本地服务器（推荐）

双击 `start.bat`，脚本会在 `8080` 端口启动一个本地服务器，并打开：

```text
http://127.0.0.1:8080/
```

也可以手动运行：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080/`。使用本地服务器时，浏览器地址和本地存储会更稳定。

## 数据说明

- 数据保存在当前浏览器的 localStorage 中，键名为 `shiguang.personaldesk.v1`
- 内部数据版本为 `4`；打开旧版数据时会自动补齐分类标签、事项标签、循环系列、循环间隔天数、顺延来源、期限记录和版本号
- 期限记录存放在同一个数据文件的 `expiries` 数组中，包含名称、类型、到期日、填写方式、生产日期、保质期数值、保质期单位、备注和创建时间
- 「进行中」不新增数据字段，由安排日期、DDL 和完成状态实时计算
- 循环任务的具体实例也会保存在 localStorage 中，因此系列较多时会占用更多空间
- 不会上传到网络，也没有账号体系
- 更换浏览器、清理站点数据或使用隐私模式可能导致数据丢失
- 首次打开会自动生成一组围绕当天的通用示例事项，可直接编辑或删除；示例数据不包含真实个人信息
